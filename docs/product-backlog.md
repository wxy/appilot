## 3. DSH 会话「活动」视图问题（待用户提供刷新错误详情）
- 现象：Electron 打开同时开 3099，DSH 会话的 Appilot 页面「活动」看不到对应工作区活动；点击刷新报错（错误文本待用户提供）
- 已确认：`appilot_tasks` 工具本身工作正常（agent 已成功查询并汇报 2391 实例）
- 待查：客户端渲染路径 / 刷新触发错误
- 架构结论（2026-09-03 查证）：DSH 客户端 UI 数据**没有插件自定义跨端直读通道**——客户端经宿主 sessions/workspaces 与**会话 agent 工具结果节点**取数，任务数据必须经 `appilot_tasks` 工具执行后订阅其结果节点渲染。因此「任务数据不经对话/工具、由客户端直读 DB」在现有 DSH 客户端模型下不可行；可行替代：
  1. 自动拉取（已做）：任务页显示即自动跑 `appilot_tasks`，结果落当前会话节点（可审计），无需手动输入
  2. 宿主桥接（待评估）：由宿主侧 cordis service 暴露 tasks 查询端点、客户端经宿主通道直读——属宿主能力扩展，需在 DSH 侧排期
- 全局面板任务数据取自「当前会话」节点 → 落在哪工作区由会话归属决定；已随主面板三标签重构收进任务页（见 #4）
