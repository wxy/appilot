## 8. UI 设计

### 8.0 设计语言：副驾驶（Co-Pilot）

> Appilot = "App 的副驾驶"。视觉**不做字面化驾驶舱**（假铆钉、圆形仪表、3D 光泽），而是把驾驶舱的**本质**翻译成三件事：全局态势感知（仪表读数）、一眼看到该做什么（副驾驶简报）、需要拍板的事被点亮（信号灯）。

**色彩 Token（双主题自适应，跟随系统）**

| Token | 深色 | 浅色 | 用途 |
|-------|------|------|------|
| 背景 | `#0A0E18` | `#F6F7F9` | 基础底色 |
| 表面 | `#111827` | `#FFFFFF` | 卡片 |
| 描边 | `#1D2432` | `#E5E8EE` | 分隔线 / 边框 |
| 主文字 | `#E9EDF4` | `#1A2030` | 正文 |
| 次文字 | `#8A94A6` | `#697386` | 次要信息 |
| 琥珀（信号） | `#F5B53F` | `#B45309` | 唯一强调色 = 指示灯 |

语义色（只在状态上出现）：`涨 #34D399` / `跌 #F87171`。

**字体（两个角色）**

- 正文：系统无衬线（SF Pro / Segoe UI），不炫技
- 数据：等宽（SF Mono / JetBrains Mono）——排名、下载、成本、token 用 mono，制造「仪表读数」质感

**信号灯语义（颜色 = 状态，不是装饰）**

| 颜色 | 含义 |
|------|------|
| 琥珀 | 需关注 / 待你确认 / 前 10 排名 / 本周行动 |
| 绿 | 上涨 / 健康 |
| 红 | 下跌 / 异常 |
| 灰 | 未进榜 / 无数据 |

**副驾驶口吻（文案规范）**

- 用副驾驶对机长说话的口气：简洁、主动、给行动而非给数字
- 词汇：本周航线 / 推荐动作 / 待你确认 / 本月已消耗 / 检测到新 Release
- 动作按钮用主动语态且名字贯穿全程（「采纳」→ toast「已采纳」）

- 链接发现：README 正则优先，找不到时 AI 兜底；多链接（`mt=12` macOS / `mt=8` iOS）时让用户选平台
- 这一阶段只建立产品档案，不生成关键词；关键词提交进入「发布工作台」，关键词跟踪进入「发布后管理」

```
│ 关键词跟踪                   [＋添加] [AI 建议] [US ▾ 商店]    │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 关键词            US   GB   CN   30天趋势                  │ │
│ │ glowalk           #2   #5   #9   ↗↗↗                     │ │
│ │ night walk        #18  #31  —    ↗↘↘                     │ │
│ │ smart flashlight  #7   —    —    ↗↗                      │ │
│ │ glow walk         —    —    —    未进榜                    │ │
│ └──────────────────────────────────────────────────────────┘ │
│  #2/#5/#9 = mono + 琥珀（前10）   — = 灰（未进榜）            │
│  [点某词 → 展开排名历史折线 + AI 归因诊断]                    │
```

- 排名数字用 mono，前 10 琥珀高亮，未进榜灰「—」
- 点某词展开：排名折线 + 「为什么涨/跌」的 AI 归因

### 8.6 素材能力（暂不单设素材中心）

发布工作台中的「推广角度」就是当前素材能力的入口。第一阶段只生成角度和文案 brief，不单独建设素材中心；后续如果图像/视频生成成为真实闭环，再决定是否重新引入独立素材库。

### 8.7 发布工作台（RELEASE_DRAFT.md → App Store 提交准备）

```
│ 发布工作台 · GloWalk                       [立即检查发布]    │
│ ┌─ 当前发布草案 · v1.2.0 · 2026-08-11 ─────────────────────┐ │
│ │ 发布公告摘要 + [打开公告文件 ↗]                           │ │
│ │ 仓库只读 · 检测到 README 可能落后于本次 Release           │ │
│ └──────────────────────────────────────────────────────────┘ │
│ 商店提交状态：已提交审核 ▾                                    │
│ 语言：[英文] [简体中文] [德文]                                │
│ ┌─ 当前语言提交文案 ───────────────────────────────────────┐ │
│ │ 推广文本 · 软件描述                                      │ │
│ │ 推广文本 45/170                                         │ │
│ │ 软件描述 820/4000                                       │ │
│ │ 新增内容 210/4000                                       │ │
│ │ 关键词 68/100                                           │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌─ 跟踪关键词调整 ─────────────────────────────────────────┐ │
│ │ + "night walking"   理由：本次 Release 新增夜间模式         │ │
│ │ - "torch"           理由：连续 30 天未进榜，本次未再强调    │ │
│ │ [应用确认]                                                │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌─ 推广角度（发布工作台内）─────────────────────────────────┐ │
│ │ 角度1 夜间场景升级       [生成文案] [生成海报 brief]        │ │
│ │ 角度2 星座路径记录       [生成文案] [生成海报 brief]        │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌─ 被驳回时（同一工作单继续迭代，不新建 Release）───────────┐ │
│ │ 驳回意见：元数据提到尚不支持的功能                         │ │
│ │ [根据驳回意见重新生成]                                     │ │
│ └──────────────────────────────────────────────────────────┘ │
│ 历史发布                                                     │
│  v1.1.0   08-02   正式发布 · 已停止生成文案 ✓                 │
```

- 以仓库根目录 `RELEASE_DRAFT.md` 的存在为主信号；仓库删除文件后不再生成文案
- 明确标注「仓库只读」；README 过时只提示，不自动修改仓库
- 同一「公告修改时间 + 产品」只保留一个提交工作单；驳回后更新草稿，不生成新 Release
- 文案按语言分成标签页，点击切换
- 每个标签页顺序为：推广文本、软件描述、新增内容、关键词
- 长度限制：推广文本 170、软件描述 4000、新增内容 4000、关键词 100
- 推广文本在商店中显示于软件描述之前，中间没有分隔
- 「推广文本」未来接 App Store Connect API 后可自动更新；当前生成后复制手动更新
- 每条内容都是可编辑、可复制、可追溯的字段；用户确认后状态推进到 `prepared → submitted → in_review → released`
- 跟踪关键词调整以增删建议呈现，用户确认后才进入或移出跟踪集
- 推广角度不直接算商店字段，而是保留在发布工作台内

### 8.11 状态与语义

**空态**（每个界面都是「行动的邀请」，而非孤零零的「无数据」）

- 项目选择器空态：「还没有项目。添加第一个，副驾驶帮你看路。」+ [添加项目]
- 关键词空态：「还没有关键词。[AI 建议] 或 [手动添加]」
- 发布工作台空态：「在仓库中创建本地发布交班文档后，确认生成商店提交文案」

**错误态**

- 说明出了什么问题 + 怎么修，不道歉、不含糊
- 例：「AI 分析失败：API Key 无效。去 [设置] 重新配置。」而非「出错了」

**动效规格（Apple 风格，克制）**

- 默认 spring `damping: 1.0`（临界阻尼，无回弹），响应 0.4s
- 只有「抛掷/拖拽」这类带惯性的交互才加一点 bounce（`damping: 0.8`）
- 尊重系统「减少动态效果」设置（reduced motion）
