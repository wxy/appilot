## 8. UI 设计

### 8.0 设计语言：副驾驶（Co-Pilot）

> Appilot = "App 的副驾驶"。视觉**不做字面化驾驶舱**（假铆钉、圆形仪表、3D 光泽），而是把驾驶舱的**本质**翻译成三件事：全局态势感知（仪表读数）、一眼看到该做什么（副驾驶简报）、需要拍板的事被点亮（信号灯）。

**色彩 Token（双主题自适应，跟随系统）**

| Token | 深色 | 浅色 | 用途 |
|-------|------|------|------|
| 背景 | `#0A0E18` | `#F6F7F9` | 基础底色 |
| 表面 | `#111827` | `#FFFFFF` | 卡片 |
| 描边 | `#1D2432` | `#E5E8EE` | 分隔线 / 边框 |
| 主文字 | `#E9EDF4` | `#1A2030` | 正文 |
| 次文字 | `#8A94A6` | `#697386` | 次要信息 |
| 琥珀（信号） | `#F5B53F` | `#B45309` | 唯一强调色 = 指示灯 |

语义色（只在状态上出现）：`涨 #34D399` / `跌 #F87171`。

**字体（两个角色）**

- 正文：系统无衬线（SF Pro / Segoe UI），不炫技
- 数据：等宽（SF Mono / JetBrains Mono）——排名、下载、成本、token 用 mono，制造「仪表读数」质感

**信号灯语义（颜色 = 状态，不是装饰）**

| 颜色 | 含义 |
|------|------|
| 琥珀 | 需关注 / 待你确认 / 前 10 排名 / 本周行动 |
| 绿 | 上涨 / 健康 |
| 红 | 下跌 / 异常 |
| 灰 | 未进榜 / 无数据 |

**副驾驶口吻（文案规范）**

- 用副驾驶对机长说话的口气：简洁、主动、给行动而非给数字
- 词汇：本周航线 / 推荐动作 / 待你确认 / 本月已消耗 / 检测到新 Release
- 动作按钮用主动语态且名字贯穿全程（「采纳」→ toast「已采纳」）

### 8.3 添加项目（产品定位向导）

```
│ 添加项目                                            1/2 步骤   │
│  ① 选本地仓库                                              │
│     [选择文件夹]   ~/develop/GloWalk                        │

│     支持语言: en-US · zh-Hans · ...                          │

```

- 链接发现：README 正则优先，找不到时 AI 兜底；多链接（`mt=12` macOS / `mt=8` iOS）时让用户选平台
- 这一阶段只建立产品档案，不生成关键词；关键词提交进入「发布工作台」，关键词跟踪进入「发布后管理」

```
│ 发布工作台 · GloWalk                       [立即检查发布]    │
│ ┌─ 当前发布 · v1.2.0 · 2026-08-11 ────────────────────────┐ │
│ │ Release 正文摘要 + [打开 GitHub Release ↗]                │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌─ 现在可改 ──────────────────────────────────────────────┐ │
│ │ Promotional Text                       [复制] [已手动更新] │ │
│ │ 生成文案：GloWalk 的夜间模式升级了——星座路径与更亮手电筒。 │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌─ 随商店版本提交 ─────────────────────────────────────────┐ │
│ │ What's New      待确认   [采纳] [修改] [忽略]              │ │
│ │ App 描述        待确认   [采纳] [修改] [忽略]              │ │
│ │ 提交关键词      待确认   100/100 字符  [采纳] [忽略]        │ │
│ └──────────────────────────────────────────────────────────┘ │
│ ┌─ 推广素材（进入素材中心）─────────────────────────────────┐ │
│ │ 角度1 夜间场景升级       [生成文案] [生成海报 brief]        │ │
│ │ 角度2 星座路径记录       [生成文案] [生成海报 brief]        │ │
│ └──────────────────────────────────────────────────────────┘ │
│ 历史发布                                                     │
│  v1.1.0   08-02   已提交 App Store ✓                         │
```

- 以 GitHub Release 为主信号（本地 git tag 兜底）
- 「Promotional Text」单独放在「现在可改」组；未来接 App Store Connect API 后显示为「自动更新」能力
- 「名称 / 副标题 / 描述 / 关键词 / What's New」放在「随商店版本提交」组，只做生成与确认，不自动写回商店
- 每条 Action 都是可执行项，而不是一段不可跟踪的文本；用户确认后状态推进到 `accepted` / `done`
- 推广角度不直接算商店字段，而是跳转或生成到素材中心

### 8.11 状态与语义

**空态**（每个界面都是「行动的邀请」，而非孤零零的「无数据」）

- 项目选择器空态：「还没有项目。添加第一个，副驾驶帮你看路。」+ [添加项目]
- 关键词空态：「还没有关键词。[AI 建议] 或 [手动添加]」
- 素材中心空态：「选择一个 Release 后，副驾驶为你生成文案、海报方向和视频脚本」

**错误态**

- 说明出了什么问题 + 怎么修，不道歉、不含糊
- 例：「AI 分析失败：API Key 无效。去 [设置] 重新配置。」而非「出错了」

**动效规格（Apple 风格，克制）**

- 默认 spring `damping: 1.0`（临界阻尼，无回弹），响应 0.4s
- 只有「抛掷/拖拽」这类带惯性的交互才加一点 bounce（`damping: 0.8`）
- 尊重系统「减少动态效果」设置（reduced motion）
