# 跟踪关键词改进设计

> 2026-08-19 · 综合用户意见与代码现状的改进规格。实现按 Phase 逐个推进（见 §9），本文档是各 Phase 的共同规格来源。

## 1. 定位：发布 vs 跟踪

- **发布工作台** = 决定「提交什么」：名称、副标题、推广文本、描述、新增内容、商店关键词（≤100 字符）。
- **跟踪关键词页** = 验证「提交的东西有没有用」：用户在某语言某商店搜索某词时，产品是否可见、排名多少。
- 跟踪集独立于提交内容：提交变了跟踪集不自动变，只在生成时参考。发布工作台**不再**向跟踪集推送增删建议（原 `trackingKeywordDeltas` 链路删除）。
- 单向联动：发布工作台确认后的提交内容（名称/副标题/商店关键词）作为跟踪页的「提交内容参考区」（只读），可「抽取候选词并加入跟踪」，候选词带来源标注，用户确认后进入跟踪集。

## 2. 术语与数据约定

- 原「英文关键词」改称**全局关键词**：存储上仍用 `language: "en"`，展示上显示为「全局」。全局关键词不专属英文语言市场，在所有本地商店的展示中都出现，并带「全局」徽标标注来源。
- 跟踪关键词条目 `KeywordEntry` 扩展（Phase 2 落地）：
  - `status: "active" | "paused"`
  - `addedAt: string`
  - `bestRank: number | null`
  - `lastSeenAt: string | null`
  - `source: "ai" | "submission" | "name" | "subtitle" | "manual"`
- 跟踪页**不生成、不编辑**商店关键词（提交字段）；提交字段只归发布工作台。存量 `submissionKeywords` 数据保留兼容，不再在跟踪页展示/编辑。

## 3. 语言点亮制（生成范围）

- 语言选择器 = 可多选的 chips，包含产品支持语言 + 「全局」（en）。
- **默认点亮界面语言**（当前 `zh-Hans`；若产品不支持界面语言，则点亮第一个支持语言）。全局默认不点亮。
- 「为所选语言生成」只对点亮语言逐个调用 AI；生成结果只含跟踪关键词（无 submission）。
- 查看（矩阵）在点亮语言中选单个语言视图；全局关键词在**每个**语言视图中都出现（带「全局」徽标），列 = 该语言对应商店。
- 与发布工作台的联动落在**语言维度**而非版本维度：母本语言可作默认建议，跟踪语言集由用户维护。

## 4. 矩阵展示

按语言选择后：

```
语言(点亮): [简体中文✓] [英文/全局] [德文]      [为所选语言生成] [采集排名]
┌─────────────┬──────────┬──────────┬──────────┐
│ 关键词        │ 美国 14:02 │ 新加坡 13:47 │ 香港 …    │
│ night walk 全│ 3 ▲2      │ 8 ▼1      │ —        │
│ 记账          │ 12 ▲0      │ 5 进榜     │ 22 ▼3    │
│ deep link   │ 200+      │ 200+      │ —        │
└─────────────┴──────────┴──────────┴──────────┘
```

- 行 = 关键词；列 = 该语言下的商店。
- 格子 = 排名 + 小号增减（▲/▼/进榜/掉榜）；Top10 用品牌色强调。
- 已查询但不在前 200：显示「200+」（与「—」未查询区分）。
- **时间**：列头下方显示该商店最近查询 `HH:mm`；超过 36h 整列降透明并标「过期」；单元格 hover 显示该词×该商店的精确 `checkedAt` 与 `totalResults`；表下方说明「各商店独立采集，时间可能不同」。
- 全局关键词行带「全局」徽标（来源标注）。
- 趋势折线降级为次要视图：点击某词展开该词在当前商店的趋势；多商店暂不叠加。

## 5. 自动屏蔽（Phase 2）

- 规则：同一关键词连续 10 次采样（或 14 天）未进榜（rank 为 null 或 >200）→ 标记 `paused`（建议屏蔽）：停止调度采集，移入「已屏蔽」分区（含原因与时间），可恢复或删除。**只屏蔽不删数据。**
- 判定放在调度 reconcile 时统一计算；已屏蔽词不再生成任务。

## 6. 采集健壮性

- `rank > 200` 与「未查询」在 UI 区分（200+ vs —）。
- 调度任务连续失败 5 次 → 暂停并标记，替代无限 30min 重试。
- snapshots 按 (keyword, language, storefront) 去重（同轮覆盖），并按 keyword×storefront 保留窗口（约 90 天），替代产品级 5000 条粗截断。
- `totalResults` 语义标注为「前 200 结果量」；竞争度/结果量第一版只在 tooltip 展示，不做排序。
- 全局关键词在非英文商店继续采集（用户会用英文在本地商店搜索），仅做 UI 标注。

## 7. 生成增强（Phase 3）

- 生成上下文：名称（含冒号后缀）、副标题、当前商店关键词（对应语言）、现有跟踪集与最近排名、已屏蔽列表、最近发布 whatsNew。
- 增量推荐（diff）：只建议新增，不重复已跟踪/已屏蔽词；每语言跟踪集上限（建议 25）。
- 候选来源：提交内容参考区「抽取候选词并加入跟踪」（商店关键词按逗号拆分；名称/副标题由 AI 抽取搜索意图词），候选带 `source`。

## 8. 暂不实现

- 「长期效果」周报/汇总页（后续模块再做）。
- 关键词竞争度排序、Top10 竞品强度（保留数据采集，不做决策）。

## 9. 分阶段路线

- **Phase 1 — 跟踪页重构**：语言点亮制；移除本页商店关键词生成与编辑；矩阵表 + 时间 + 200+ + 全局徽标；删除 release deltas 链路；术语「全局」。
- **Phase 2 — 自动屏蔽**：KeywordEntry 扩展；连续未进榜自动屏蔽 + 恢复/删除；调度跳过屏蔽词；snapshots 去重与保留窗口；失败重试上限。
- **Phase 3 — 生成增强与联动**：提交内容参考区 + 抽取候选；diff 增量 + 上限；生成上下文增强。
- **Phase 4 —（以后）**：趋势汇总、竞争度排序。
